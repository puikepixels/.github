## 🛠️ Development principles

**Keep it simple.**  
Complexity should have a reason.

**Build reusable.**  
If we solve something twice, we look for a way to solve it once.

**Automate the boring stuff.**  
Less repetitive work. More time for useful work.

**Dogfood your own software.**  
If we build it, we use it.

**Ship & improve.**  
Good software is never really finished.
